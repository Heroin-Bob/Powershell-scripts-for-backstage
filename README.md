# Tools

Portable utilities bundled with this dashboard. Each tool is a standalone program that is downloaded on demand and run from a temporary folder.

| # | Tool | More Info | What It's Useful For |
|---|------|-----------|----------------------|
| 1 | BleachBit | [bleachbit.org](https://www.bleachbit.org/) | Free system cleaner that removes caches, temp files, logs, and other clutter to free up disk space and protect privacy. |
| 2 | CPU-Z | [cpuid.com](https://www.cpuid.com/softwares/cpu-z.html) | Details your CPU, motherboard, memory, and OS, and lets you identify hardware components and verify specs. |
| 3 | Explorer++ | [explorerplusplus.com](https://explorerplusplus.com/) | A multi-tabbed file manager for Windows that makes it easier to browse, copy, move, and organize files. |
| 4 | Geek Uninstaller | [geekuninstaller.com](https://geekuninstaller.com/) | Lightweight uninstaller that removes programs and performs deep scans for leftover files, folders, and registry entries. |
| 5 | HWMonitor | [cpuid.com](https://www.cpuid.com/softwares/hwmonitor.html) | Reads hardware sensors to report voltages, temperatures, and fan speeds, helping you check system health and cooling. |
| 6 | IObit Uninstaller Portable | [iobit.com](https://www.iobit.com/en/advanceduninstaller.php) | Removes stubborn programs, browser extensions, and leftover files that standard uninstallers miss. |
| 7 | Kudu Portable | [usekudu.com](https://usekudu.com/) | Free, open-source maintenance suite for cleaning junk, debloating Windows, optimizing performance, and monitoring your system. |
| 8 | SeaMonkey | [seamonkey-project.org](https://www.seamonkey-project.org/) | An all-in-one internet suite combining a web browser, email and newsgroup client, and HTML editor in a single program. |
| 9 | Local Keyboard/Mouse Test | [Powershell-scripts-for-backstage](https://github.com/Heroin-Bob/Powershell-scripts-for-backstage) | A local HTML-based tester that verifies keyboard and mouse functionality by showing which keys, buttons, and movements register. |
| 10 | Speedtest CLI | [speedtest.net/apps/cli](https://www.speedtest.net/apps/cli) | Runs a network speed test from the command line to measure download, upload, and ping against speedtest.net servers. |
| 11 | TreeSize Free | [jam-software.com](https://www.jam-software.com/treesize_free) | Analyzes disk usage to find which folders and files are taking up the most space on a drive. |
| 12 | InstallerClean | [github.com/no-faff/InstallerClean](https://github.com/no-faff/InstallerClean) | Open-source tool that safely cleans orphaned files from the Windows Installer cache (`C:\Windows\Installer`) to reclaim disk space. |
| 13 | InstallerClean CLI | [github.com/no-faff/InstallerClean#command-line](https://github.com/no-faff/InstallerClean#command-line) | The command-line version of InstallerClean for scanning and cleaning orphaned Windows Installer files headlessly. |
